# المنظومة الوطنية للاعتماد والإعلام الرياضي (Sports Media Platform)

منظومة إلكترونية متكاملة للإعلاميين الرياضيين تتيح التسجيل الرقمي، حفظ البيانات في قاعدة بيانات، اعتماد الطلبات إدارياً، وإصدار بطاقات صحفية ذكية مزودة برمز QR قابلة للطباعة فورياً.

---

## 🌟 أبرز مميزات المنظومة

1. **بوابة تسجيل إعلامي متكاملة (`/register`):**
   - تسجيل البيانات الشخصية، بيانات الاتصال، فصيلة الدم للطوارئ.
   - تحديد المؤسسة الإعلامية (قناة فضائية، صحيفة، إذاعة، منصة رقمية، وكالة).
   - تحديد الصفة الصحفية (مراسل ميداني، مصور فوتوغرافي، معلق، محرر، صانع محتوى).
   - رفع الصورة الشخصية والوثائق الرسمية مع معاينة حية لشكل البطاقة فورياً أثناء الكتابة.

2. **ملف رقمي وصفحة مخصصة لكل إعلامي (`/media-card/[id]`):**
   - صفحة عامة موثقة برمز QR يمكن لأي منظم أو حارس بوابة مسحه للتحقق الفوري من صحة سريان البطاقة.
   - إمكانية استعراض وجهي البطاقة (الأمامي والخلفي).
   - إمكانية مشاركة رابط التوثيق المباشر.

3. **تصميم بطاقات اعتماد احترافية قابلة للطباعة (`/media-card/[id]/print`):**
   - متوافقة بدقة مع طابعات كروت الـ PVC وشارات التعليق (Lanyards).
   - مجهزة بفتحة التعليق، الباركود، ختم الهولوجرام الأمني، وتوزيع مناطق الدخول (Zones).
   - تدعم طباعة الوجهين معاً للطي والتغليف الحراري أو كل وجه على حدة بضغطة زر واحدة.

4. **لوحة تحكم إدارية شاملة (`/admin`):**
   - إحصائيات حية: إجمالي المسجلين، الطلبات قيد الانتظار، المعتمدة، والمرفوضة.
   - تصفية وبحث سريع بالاسم أو المؤسسة أو رقم الهوية أو كود الاعتماد.
   - مراجعة المستندات واعتماد البطاقة بضغطة زر مع تخصيص مناطق الدخول (Zone Access).
   - إمكانية الرفض مع تدوين السبب أو حذف السجلات.

## 🚀 كيفية التشغيل محلياً (Local Run)

1. الدخول لمجلد المشروع:
```bash
cd "C:\Users\ghani\.gemini\antigravity\scratch\sports-media-platform"
```

2. تشغيل خادم التطوير:
```bash
npm run dev
```
أو تشغيل النسخة الإنتاجية الجاهزة:
```bash
npm start
```

3. فتح المتصفح على:
```
http://localhost:3000
```

## 🌐 كيفية رفع المنظومة على شبكة الإنترنت (Deployment Guide)

### الخيار 1: الرفع السريع والمجاني عبر منصة Vercel (الأسهل والأفضل لـ Next.js)
1. قم بإنشاء حساب مجاني على [Vercel](https://vercel.com).
2. قم برفع مجلد المشروع إلى حسابك على GitHub أو GitLab.
3. اضغط على **"Add New Project"** في Vercel واختر المستودع.
4. اضغط **Deploy**؛ وستحصل فوراً على رابط رسمي مجاني وسريع (مثل: `https://sports-media.vercel.app`).

### الخيار 2: الرفع على خادم افتراضي VPS (Ubuntu / Linux)
1. تثبيت Node.js و PM2:
```bash
sudo apt update && sudo apt install -y nodejs npm
sudo npm install -g pm2
```
2. رفع ملفات المشروع وتشغيلها كخدمة دائمة:
```bash
npm install
npm run build
pm2 start npm --name "sports-media" -- start
```
3. ربط النطاق (Domain) عبر Nginx وشهادة SSL مجانية (Certbot).

## 📂 هيكلية المشروع (Project Structure)

```
sports-media-platform/
├── data/
│   └── journalists.json      # قاعدة البيانات المحفوظة (سجلات الإعلاميين)
├── src/
│   ├── app/
│   │   ├── page.jsx          # الصفحة الرئيسية وبوابة التحقق
│   │   ├── register/         # صفحة تسجيل الإعلامي الجديد
│   │   ├── admin/            # لوحة تحكم المشرفين والاعتماد
│   │   ├── media-card/[id]/  # صفحة ملف الإعلامي والتحقق بالـ QR
│   │   │   └── print/        # صفحة الطباعة المخصصة للبطاقة
│   │   └── api/journalists/  # واجهة برمجة التطبيقات (API)
│   ├── components/
│   │   └── PressCard.jsx     # مكون بطاقة الاعتماد الذكية (أمام وخلف)
│   └── lib/
│       └── db.js             # مدير قاعدة البيانات والعمليات
└── tailwind.config.js        # إعدادات التصميم والهوية البصرية
```
